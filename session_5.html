국내 로컬푸드협동조합 혁신사례 — 지금 실행하고, 휴식 동안 AI가 조사합니다

M4심층 리서치 실행하기

국내 로컬푸드협동조합 혁신사례 조사 보고서

  1. 새 대화 열기‘제천로컬푸드 업무비서’ 프로젝트에서
  2. 심층 리서치 선택 → 입력도구에서 심층 리서치 선택 후 아래 프롬프트 붙여넣기
  3. 확인 질문에 답하기범위 확인 질문에 답한 뒤 휴식
국내 로컬푸드협동조합의 혁신사례를 조사해서 보고서로 정리해줘.
- 국내 사례 5곳 이상, 최근 3년 이내 자료 우선
- 사례별 혁신 내용, 성과 수치, 출처 링크, 발표일을 표로 정리
- 확인되지 않은 수치는 '확인 필요'로 표시
- 마지막에 공통 성공 요인과, 직매장 3곳·온라인몰·꾸러미를 운영하는 중소도시 협동조합에 적용할 아이디어 3가지
☕ 쉬는 시간 · 10분심층 리서치가 조사하는 동안 잠시 쉬어 갑니다.

M3일반 대화 vs ChatGPT Work

Work = 목표를 맡기고, 중간 승인과 최종 검토는 사람이

일반 대화

  • 한 번 묻고 한 번 답하기
  • 결과물을 하나씩 따로 요청
  • 단계마다 내가 지시
  • 짧은 작업에 적합

ChatGPT Work

  • 목표를 주면 단계별로 끝까지 진행
  • 슬라이드 · 문서 · 시트를 완성본으로
  • 중요한 단계에서 멈추고 승인 요청
  • 오래 걸리는 작업도 이어서 진행

※ 2026년 7월 발표 기능 · 요금제와 화면 구성은 계정·버전마다 다를 수 있습니다

프로젝트와 Work의 관계

프로젝트는 ‘기억하는 업무 공간’, Work는 ‘끝까지 해내는 실행자’

프로젝트 — 업무 서랍 · 기억

  • 지침 일하는 규칙 · 문체
  • 참고 파일 조합소개 · 양식 · 예시
  • 대화 기록 이전 결정 · 결과물

→ 맥락 제공 (지침 · 파일)

Work — 목표를 받아 끝까지 해내는 실행자

  1. 목표 받기
  2. 계획 세우기
  3. 실행 (자료 분석 · 작성)
  4. 사람이 확인 · 승인
  5. 결과물 완성 (슬라이드 · 문서 · 시트)

→ 결과물 저장 → 다음에 재사용

실제 예업무비서 프로젝트 (지침 · 양식) + 정제본 첨부 + Work → 이사회 보고 슬라이드 3장 + 요약 문서 → 다시 프로젝트에 저장

M3Work로 이사회 보고 ① 판매데이터

사용 자료 판매데이터_정제본 (라이브러리) · ‘제천로컬푸드 업무비서’ 프로젝트에서 Work로 새로 시작합니다

  1. Work 새 채팅프로젝트 화면에서 ‘Work’ 선택
  2. 정제본 첨부입력창 아래 ‘파일’ → 라이브러리에서 ‘판매데이터_정제본’
  3. 프롬프트 입력아래 프롬프트 붙여넣기 → 구성안 확인 · 승인
첨부한 판매데이터 정제본으로 매장·품목·월별 매출을 분석해서 이사회 보고 자료를 만들어줘.
[결과물] 보고 슬라이드 3장(현황·분석·개선 제안) + 1쪽 요약 문서
[수치] 정제 데이터 기준, 해석은 '추정'으로 표시
[디자인] 흰 배경, 제목 남색(#17365D), 강조 파랑(#2E66B3), 제목 32pt·본문 18pt, '210 디딤고딕'(없으면 맑은 고딕)
[확인] 슬라이드를 만들기 전에 구성안을 먼저 보여주고 내 확인을 받아줘

M3Work로 이사회 보고 ② 혁신사례 보고서 가안

사용 자료 심층 리서치 보고서 (라이브러리) · 심층 리서치 보고서가 완성됐을 때 진행 — 만들어진 보고서를 그대로 첨부합니다

  1. Work 새 채팅프로젝트 화면에서 ‘Work’ 선택
  2. 보고서 첨부입력창 아래 ‘파일’ → 라이브러리에서 ‘국내 로컬푸드…’
  3. 프롬프트 입력아래 프롬프트 붙여넣기 → 구성안 확인 · 승인
첨부한 '국내 로컬푸드협동조합 혁신사례' 보고서로 이사회 보고 자료를 만들어줘.
[결과물] 보고 슬라이드 3장(사례 요약·공통 성공 요인·우리 조합 적용안) + 1쪽 요약 문서
[출처] 사례마다 출처와 발표일 표시, 확인 안 된 수치는 '확인 필요'
[디자인] 흰 배경, 제목 남색(#17365D), 강조 파랑(#2E66B3), 제목 32pt·본문 18pt
[확인] 슬라이드를 만들기 전에 구성안을 먼저 보여주고 내 확인을 받아줘

M3진행 확인 · 승인 · 결과 검토

Work는 맡기되, 구성안 승인과 최종 검토는 사람이 합니다.

  1. 구성안 확인목차 · 핵심 메시지 승인 또는 수정
  2. 진행 중 방향 수정‘2장에 매장별 그래프 추가해줘’
  3. 결과 검토아래 체크리스트로 최종 확인

결과 검토 체크리스트

  • 원본 · 분석표 · 자료 숫자 일치
  • 한 장에 메시지 하나
  • 결론이 보이는 제목
  • 이사회 눈높이 (전문용어 최소화)
  • 기간 · 출처 표기
  • 글자 크기 · 그래프 한글 확인
이 자료를 이사회 위원 입장에서 검토하고, 이해하기 어려운 부분 3가지를 지적해줘.
